# Diario di bordo

Una voce per ogni incontro: cosa si è fatto, cosa ha funzionato, cosa riprendere la volta dopo. Serve a tenere memoria del percorso mentre lo si fa — e, a fine anno, a scrivere la relazione finale senza ricostruire tutto a memoria.

## Come si aggiunge una voce

Copia [`_template-incontro.md`](_template-incontro.md) e rinominalo con data e numero dell'incontro:

```
diario/2026-11-27-incontro-01.md
```

Data in formato `AAAA-MM-GG`, così i file si ordinano da soli in ordine cronologico. Il numero progressivo conta gli incontri effettivi, non le settimane di calendario.

## Attenzione ai dati degli studenti

**Questo repository è pubblico.** Tutto ciò che scrivi nel diario è leggibile da chiunque, e resta nella storia di git anche se poi lo cancelli.

Nelle osservazioni sui ragazzi usa quindi iniziali o descrizioni di ruolo (*"il gruppo dei bassi"*, *"A. alla batteria"*), non nomi e cognomi, e non annotare informazioni su situazioni personali, familiari, di salute o certificazioni. Se hai bisogno di tenere note di quel tipo, vanno fuori da qui.
