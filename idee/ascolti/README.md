# Ascolti

Brani ed esempi da proporre in classe. Un file per ascolto, oppure un file per percorso tematico se più brani stanno insieme.

Per ogni ascolto conviene annotare quattro cose:

- **Cosa si ascolta** — titolo, autore, anno, e un link (YouTube, Bandcamp, archivi online)
- **Quanto** — il minutaggio dello spezzone utile: con una classe di prima media raramente si va oltre i due o tre minuti
- **Perché qui** — quale parametro del suono o quale idea illumina, e a che punto del percorso serve
- **Cosa chiedere** — la domanda da fare dopo l'ascolto, che è la parte che decide se l'ascolto funziona o cade nel vuoto

Vale la pena coprire territori diversi: musica concreta e paesaggio sonoro, minimalismo e processi ripetitivi, improvvisazione libera, elettronica da club, e musica che i ragazzi già ascoltano — riletta però con le orecchie del laboratorio.
